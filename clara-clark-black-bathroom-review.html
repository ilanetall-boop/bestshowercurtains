Frequently Asked Questions

What's included in the Clara Clark Black Bathroom Set?

The set is sold as one complete package rather than piece by piece, built from a polyester shell over a PEVA lining. That combination pairs a fabric-like exterior finish with a water-resistant inner layer, which is why the listing does not call out a separate liner as a required add-on.

Is the Clara Clark Black Bathroom Set machine washable?

Polyester components generally tolerate a cold, gentle machine cycle, but PEVA is a heat-sensitive plastic film that can warp or crack in a hot wash or dryer. Check the care tag included with your set before washing, and when in doubt, hand wipe the PEVA sections instead of machine washing the whole set.

Does the Clara Clark Black Bathroom Set need a separate liner?

Not necessarily. The PEVA component in this set is a built-in liner layer, a different approach from a purely decorative fabric curtain that requires buying a liner separately. Adding a dedicated liner is still an option for extra water protection on a curved or walk-in setup, though it is not a requirement out of the box.
